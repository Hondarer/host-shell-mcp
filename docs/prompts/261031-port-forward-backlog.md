## BL-001 Unix ドメイン ソケットと UDP の転送

- **現状の事象**: 転送対象は TCP だけです。Docker ソケットなどの Unix ドメイン ソケットや、DNS などの UDP は転送できません。
- **摘出契機**: 前提検討時に、転送できる通信の種別を TCP だけとする決定に伴い見送りました。
- **補足**: 整理時に起票レベルへ詳細化します。

## BL-002 接続先で待ち受けるポート番号の許可範囲

- **現状の事象**: リモート転送で接続先が待ち受けるポート番号を、接続先の管理者が制限する手段がありません (ssh の `PermitListen` 相当がない)。
- **摘出契機**: 前提検討時に、接続先側ではポート番号を制限せず OS の制約に従う決定に伴い見送りました。
- **補足**: 整理時に起票レベルへ詳細化します。

## BL-003 HTTP プロキシの接続の接続先監査ログへの記録

- **現状の事象**: クライアント経由 HTTP プロキシの接続 (宛先、結果) は bridge の proxy_status と stderr にだけ記録され、接続先の監査ログには記録されません。ポート転送の待ち受けと発信は接続先の監査ログに記録するため、機能間で記録の範囲が異なります。
- **摘出契機**: 前提検討時に、接続先の監査ログへ転送を記録する決定に伴い、既存機能の仕様変更として見送りました。
- **補足**: 整理時に起票レベルへ詳細化します。
