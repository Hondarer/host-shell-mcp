# Past work records

[English](#english) | [日本語](#日本語)

## English

> [!IMPORTANT]
> The files in this folder are snapshots of past work: discussions, final specifications and backlogs written while each task was in progress. They record what was known and decided at that time, and **may differ from the current state** of the code and documents. For the current specification, see the documents in [`docs/`](../../README.md).

- The records are written **in Japanese only**. Only this README is in both English and Japanese.
- File names start with the date the work was done, as `yymmdd-` (for example, `261031-` is 2026-10-31).

## 日本語

> [!IMPORTANT]
> このフォルダーのファイルは、過去の作業の断面の記録です。各作業の途中で書いた検討、最終仕様、残課題を収めています。記録した時点で分かっていたことと決めたことを残したものであり、**現在のコードや文書の状況とは異なる場合があります**。現在の仕様は [`docs/`](../../README.md) の文書を参照してください。

- 記録の内容は**日本語のみ**です。英語と日本語の両方で書いているのは、この README だけです。
- ファイル名の先頭には、作業した日付を `yymmdd-` の形で付けています (例: `261031-` は 2026-10-31)。
