# Copilot CLI のコピー範囲の検証記録 (2026-11-03)

> [!IMPORTANT]
> 作業時点の記録です。現在の手順と制限は [Copilot CLI のコピーが動作しない場合](../../ja/coding-agents.md#copilot-cli-のコピーが動作しない場合) を参照してください。

推奨手順 (`Terminal: Select All` → `Terminal: Copy Selection`) で、画面の表示範囲より前の出力がコピーされるかを確認しました。

## 環境

[Copilot CLI の操作段階の検証記録](261103-copilot-cli-operation-validation.md) と同じ環境を続けて使用しました。code-server 4.144.0 のターミナル、Copilot CLI 1.0.83 (マウス操作有効)、Chrome for Testing 148 (WSLg) を CDP で操作し、コマンド パレットは `F1` から実行しました。コピー結果は、事前に Windows のクリップボードを目印の文字列で上書きしたうえで、PowerShell の `Get-Clipboard` で読み出しました。

## 結果

| 対象 | 状態 | コピーされた内容 |
|---|---|---|
| Copilot CLI | L001〜L120 の 120 行を応答させ、画面には L082〜L120 が表示 | L082〜L120 の 39 行と、タブ・枠・入力欄・ステータス行。L001〜L081 は含まれない |
| Copilot CLI | ホイールで上へスクロールし、L064〜L103 を表示 | L064〜L103 の 40 行と枠など |
| 通常のシェル (bash) | `seq -f 'S%03g' 1 300` を実行 | S001〜S300 の 300 行すべてとプロンプト行 (スクロールバックを含む) |

Copilot CLI は全画面の TUI として独自にスクロールを処理しており、ターミナル側のスクロールバックには会話が残らないため、そのとき表示されている範囲だけが対象になると考えられる。PowerShell で読み出した罫線などの文字化けは読み出し時の文字コードによるもので、コピー内容とは別である。
